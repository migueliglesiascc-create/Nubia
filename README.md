Nubia es una aplicación educativa de participación en tiempo real. El docente plantea una pregunta, comparte un código QR y observa cómo las respuestas del alumnado cobran vida en una nube de palabras.

La experiencia está diseñada para el aula: rápida para el estudiante, visual durante la proyección y útil para el maestro cuando necesita comprobar, valorar o imprimir la participación.

## La experiencia Nubia

1. El maestro escribe una pregunta y crea una sesión.
2. Nubia genera un código y un QR.
3. Cada estudiante entra con su nombre y apellidos y responde con una palabra.
4. Las palabras más repetidas aparecen más grandes.
5. La proyección transforma las respuestas en una composición viva y multicolor.
6. El mural de participación agrupa todas las intervenciones por estudiante.
7. El docente puede revisar, descartar, restaurar e imprimir un informe.

## Funciones principales

- Nube de palabras actualizada en tiempo real.
- Acceso del alumnado mediante QR o código de sesión.
- Experiencias separadas para docente y estudiante.
- Vista de proyección optimizada para el aula.
- Palabras horizontales y verticales con tamaño proporcional a su frecuencia.
- QR permanente en la proyección para quienes llegan tarde.
- Mural de participación con un post-it por estudiante.
- Descarte y restauración de participaciones dudosas.
- Informe imprimible con selección de estudiantes, crédito, valoración y observaciones.
- Modos claro y oscuro.
- Diseño adaptable a ordenador, tableta y móvil.

## Tecnología

Nubia funciona con herramientas accesibles para cualquier centro educativo:

- Google Apps Script como servidor y aplicación web.
- Google Sheets como almacenamiento de sesiones y respuestas.
- HTML, CSS y JavaScript en una interfaz sin dependencias de compilación.

El repositorio contiene el código fuente. La aplicación en funcionamiento se publica desde Google Apps Script; GitHub Pages no sustituye el servidor ni la hoja de cálculo.

## Instalación

Consulta [INSTALACION.md](INSTALACION.md) para crear una copia conectada a tu propia hoja de cálculo y publicar la aplicación web.

## Privacidad educativa

Nubia puede recoger nombres y respuestas del alumnado. La hoja conectada no forma parte de este repositorio y debe permanecer bajo el control del docente o del centro.

Antes de usarla con estudiantes, consulta [PRIVACIDAD.md](PRIVACIDAD.md).
